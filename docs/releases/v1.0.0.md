# Memminning v1.0.0 — first public preview

Memminning helps Linux gamers inspect memory use, review temporary changes to background activity, and restore their original settings after a session.

This is the first GitHub release. The earlier 0.x versions were local development iterations. Version one is a **public preview**, not a claim of production certification or universal device compatibility.

## Included

- Native GTK dashboard, searchable inventory and optional GNOME 51 panel launcher.
- Reviewed GNOME extension disabling, allowlisted optional user-service stops and soft memory limits.
- Private atomic recovery journal, independent restoration timer, manual/login recovery and diagnostic logs.
- Eight optional character portraits, game filters, custom avatars, milestones, history, Professional Mode and reduced motion.
- Per-user installer, dependency checks and explicit checksum-verified optional artwork downloads.
- Installation, usage, compatibility, safety, troubleshooting and developer guides; issue templates and CI.

## Install

Follow the [installation guide](https://github.com/Shizzzzoo/memminning/blob/v1.0.0/docs/INSTALLATION.md). Source archives require system Python, GTK/PyGObject, libadwaita and systemd. Download the attached archive and checksum list, verify with `sha256sum -c SHA256SUMS`, then run `install.py` as your desktop user. Add `--with-character-art` for the optional portraits.

## Tested scope and limits

The primary target is x86-64 Arch Linux, GNOME 51, Wayland. Validation covers core/progress/artwork tests, real GTK interactions with simulated system actions, live read-only scanning, and an empty-session systemd timer test. Other desktops have partial discovery; their plugin control is not implemented. Broader live target/failure and fresh-login launcher validation remain outstanding.

No fixed RAM saving or FPS improvement is guaranteed. Review the [safety model](https://github.com/Shizzzzoo/memminning/blob/v1.0.0/docs/SAFETY.md) before applying a session. Full character images are not redistributed in the source archive and remain outside the MIT code license.

## Support

Report reproducible issues with your versions and redacted diagnostics through [GitHub Issues](https://github.com/Shizzzzoo/memminning/issues). Preserve the recovery journal if a session needs attention.
