# Roadmap

v1.0.0 is the first public preview: native gaming dashboard, reviewed resource controls, optional character portraits, recovery timers, local progress, documentation and CI.

Next validation work:

- Test panel loading in fresh GNOME 51 logins and assess other GNOME versions in disposable sessions.
- Exercise real target stop/limit/restore, GUI crashes, disk-full and reboot recovery on disposable systems.
- Measure RAM/latency outcomes before making performance claims.
- Validate other distributions and architectures; publish evidence-backed compatibility updates.

Potential features:

- Desktop-specific reversible action adapters for KDE/Cinnamon after risk and restoration design.
- Explicit custom profile paths, container and GPU discovery with coverage reporting.
- User-created session profiles that always revalidate targets and never preselect newly discovered items.
- Distro packaging, signed releases and opt-in update checks after a release process is established.

Unknown processes and browser extensions will not become actionable merely because they consume memory. No schedule or support commitment is implied by this list.
